# Kicknode Sound System — Site & Visualiseur 3D

Site complet React + TypeScript + Tailwind CSS intégrant le visualiseur 3D (`@react-three/fiber`) de la façade Kicknode Sound System.

## Installation et lancement

1. **Copier vos modèles 3D** dans le dossier `public/` :
   - `step1_2.obj` & `step1_2.mtl`
   - `step2_2.obj` & `step2_2.mtl`
   - `step3_2.obj` & `step3_2.mtl`

2. **Installer les dépendances** :
   ```bash
   npm install
   ```

3. **Lancer le serveur de développement** :
   ```bash
   npm run dev
   ```
